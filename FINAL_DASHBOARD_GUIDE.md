# Final Dashboard: Quick Guide

## Start the app
Run `python -m pip install -r requirements.txt`, then `python -m streamlit run dashboard.py` from this folder.

## Recommended demo order
1. Overview — explain what the dataset covers.
2. Music Preferences — compare favourite genres.
3. Listening Habits — discuss frequency, hours and situations.
4. Music & Mood — show reported moods and effects.
5. Statistical Visualisation — explain each Seaborn plot.
6. K-Means Clustering — change K and compare average score profiles.
7. Classification Models — choose a target, train models and explain the test metrics.
8. Research Tests — explain p-values and the 0.05 significance threshold.
9. Data Explorer — show filters and data-quality information.

## Important limitations to mention
- The supplied data is labelled synthetic.
- Clusters are exploratory groups, not official respondent types.
- Classification results are only a learning experiment on this dataset.
- The hypothesis results displayed on the Research Tests page were copied from the mid-review presentation and should be rechecked against the latest code before the final report.
